# 🍽️ Aminih Musda Catering — Official Website

Professional catering service website for **Aminih Musda Catering (AMC)** — serving Jakarta and Jabodetabek area since 2004.

## 🌐 Live Site
- **Production**: `https://aminihmusdacatering.com` (pending deployment)
- **Local Preview**: Open `index.html` in your browser

## 📋 Project Overview

Single-page responsive website showcasing AMC's catering services with:
- Hero section with brand logo and company tagline
- About section with company history (since 2004)
- Core values: Halal, Terjangkau, Enak
- 6 service offerings (Nasi Box, Prasmanan, Wedding, Tumpeng, Snack Box, Aqiqah)
- Filterable menu catalog
- Customer testimonials with auto-scroll
- Contact section with WhatsApp integration
- Comprehensive SEO optimization

## 🛠️ Tech Stack

- **HTML5** — Semantic markup with structured data (JSON-LD)
- **CSS3** — Custom properties (design tokens), animations, responsive design
- **Vanilla JavaScript** — No frameworks, lightweight and fast
- **Google Fonts** — Playfair Display, Poppins, Cormorant Garamond

## 🚀 Deployment

### Local Development
```bash
# No build step required - just open in browser
start index.html
```

### Production Deployment (Recommended: Netlify/Vercel)

**Option A: Netlify**
```bash
# Install Netlify CLI
npm install -g netlify-cli

# Deploy
netlify deploy --prod
```

**Option B: Vercel**
```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel --prod
```

**Option C: GitHub Pages**
1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Set source to `main` branch `/` (root)
